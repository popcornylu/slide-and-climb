# slide-and-climb

A responsive web-based Snakes and Ladders board game with random board generation.

## Play

https://popcornylu.github.io/slide-and-climb/

## Features

- 10x10 board with randomly generated snakes and ladders each game
- 2-4 players, each configurable as human or computer
- Spinning wheel (1-6) with smooth animation
- Step-by-step movement and ladder/snake transport animations
- Responsive layout for mobile phones and iPads
- Zero dependencies — pure HTML, CSS, and JavaScript
